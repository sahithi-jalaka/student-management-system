
# Student Management System

## 📌 Project Overview

The **Student Management System** is a web-based application developed using PHP, HTML, and MySQL. It helps manage student records efficiently by allowing users to add, view, edit, and delete student details.

## ✨ Features

- **Add Student:** Register new students and save their details.
- **Display Students:** View the list of registered students.
- **Edit Student:** Update existing student information.
- **Delete Student:** Remove student records from the database.
- **Database Management:** Store and manage student information using MySQL.
- **User-Friendly Interface:** Simple interface built using HTML and PHP.

## 🛠️ Technologies Used

- **Frontend:** HTML
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP)

## ⚙️ Installation and Setup

1. Install [XAMPP](https://www.apachefriends.org/).
2. Clone or download this repository.
3. Copy the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP control panel.

### Database Setup

1. Open phpMyAdmin at `http://localhost/phpmyadmin`.
2. Create a database named `student_management`.
3. Create the required student table with columns matching your PHP code.
4. Configure your database connection in `db.php` with the correct database name, username, and password.

### Run the Project

Open your browser and visit:

```text
http://localhost/student-management-system/
```
